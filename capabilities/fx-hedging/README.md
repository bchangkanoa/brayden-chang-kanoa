
# FX Hedging

This capability will analyze foreign exchange risk for a U.S. surgical robotics manufacturer expecting to receive €9,400,000 in 365 days.

The project will compare forward contracts, money-market hedges, and currency put options to evaluate their effectiveness in managing exchange-rate risk.

## Stage 2 — Model Specification

The technical specification outlines the model's inputs, assumptions, calculations, outputs, and sensitivity analysis. It provides the foundation for building the Excel hedging model in Stage 3.

- [Technical Specification](spec.md) — Documents the model structure, formulas, and validation checks.
- [AI Prompt Log](prompt-log.md) — Documents how ChatGPT was used to help organize, review, and revise the specification.

## Next Steps

In Stage 3, the technical specification will be used to build and test the Excel hedging model. Stage 4 will replace indicative market inputs with live data, and Stage 5 will evaluate the results and provide a final hedging recommendation.
